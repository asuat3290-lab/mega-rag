# Repository scope

This private repository contains the current reviewed MegaRAG source and docs.
Its local code history was exported using an allow-list of reviewed paths;
commit hashes differ from the original repository. The original Git repository
and its uncommitted changes remain untouched locally.

Live databases, vector stores, source text collections, import receipts,
deployment configuration, diagnostic outputs and generated research reports
are excluded. Existing test fixtures and terminology rules are source assets,
not an uploaded corpus. Copy config.example.yaml to a local config.yaml and
provide your own local data. No new license is granted by this upload.
